# 故障排查与已知限制

[← 中文 README](../README.zh-CN.md) · [English README](../README.md)

## 先做这三件事

1. 打开 `帮助 → 调试输出`，过滤 `Sense Lingo`；在设置里勾选「输出调试日志」能看到更细的链路。
2. 确认 `设置 → Sense Lingo` 里 API Key / 接口地址 / 模型都已填写（`Custom` 也必须填 Key）。
3. 用快捷键 `Ctrl/⌘ + Shift + T` 打开结果面板——它会显示判定类型、模板名、命中的原句、
   模型与耗时，比弹窗里的纯译文信息多得多。

## 快速自查

| 症状                   | 优先检查                                                         |
| ---------------------- | ---------------------------------------------------------------- |
| 装不上 / 提示不兼容    | `strict_max_version` 是否小于当前 Zotero 版本                    |
| 划词后没有「翻译」按钮 | 是否开了「自动翻译」、`showInPopup` 是否被关、API Key 是否已配置 |
| 快捷键没反应           | 当前文档里是否至少划过一次词（快捷键在首次弹窗渲染时绑定）       |
| 提示「未取到上下文」   | PDF 是否有文本层（扫描版需先 OCR）                               |
| 句子对不上             | 同一个词出现多次且没有选区指纹（见下文「重复词定位」）           |
| 提示认证失败           | Key 是否正确、是否有该模型权限、`baseURL` 是否多/少了 `/v1`      |
| 提示网络失败           | 代理 / 防火墙；中国大陆访问 OpenAI 通常需要代理                  |
| 请求超时               | 调大「请求超时」或换更快的模型                                   |
| 音标不准               | 音标由模型生成，罕见词请以词典为准                               |

## 常见问题

### Zotero 升级后装不上

Zotero 用 `strict_max_version` 做硬性拦截。当前清单是 `7.0` – `11.*`，Zotero 升到更高大版本后
会提示「它可能无法与该版本的 Zotero 兼容」。解决办法：

1. 改 `addon/manifest.json` 的 `strict_max_version`；
2. `npm run build`；
3. 用新的 `.scaffold/build/sense-lingo.xpi` 重新安装。

排查打包产物里的真实值：

```bash
unzip -p .scaffold/build/sense-lingo.xpi manifest.json | grep strict_
```

### 划词后没有翻译按钮

按顺序确认：

- 设置里 `showInPopup` 是否打开；
- 是否开了 `autoTranslate`——开启后按钮会隐藏，选中文本就直接出译文；
- 是否配置了 API Key：自动翻译在未配置时会**静默跳过**，不会弹错误；
- 是否在 PDF / EPUB 阅读器里划词；主窗口只支持快捷键；
- 该 PDF 是否是扫描版（没有文本层时仍然能翻译，但会缺上下文）。

### 快捷键没反应

- 阅读器里的 `keydown` 监听是在该文档**第一次渲染划词弹窗时**绑定的：打开新文献后先划一次词，
  之后快捷键才可用；
- 确认设置里 `shortcutEnabled` 已勾选；
- 快捷键必须在有选中文本时按下：主窗口用实时选区，阅读器里优先用最近一次划词记录。
- 主窗口里也能用，但没有附件上下文，只做纯词义翻译。

### 提示「未取到上下文」

说明三层文本来源（附件全文缓存 → 阅读器文档 → EPUB 解析）都没有定位到选中词：

- 扫描版 / 图片型 PDF：没有文本层，先做 OCR；
- 双栏、页眉页脚、脚注混排可能让句子边界偏移，此时会退化为窗口截断或纯词义翻译；
- EPUB 第一次触发要读整本书，可能慢 1～3 秒，之后按附件缓存。

### 划词被当成句子 / 划句被当成词

典型误判：

| 选区               | 判定       | 原因                          |
| ------------------ | ---------- | ----------------------------- |
| `Not really.`      | `sentence` | 含句末标点且不止一个 token    |
| `state of the art` | `sentence` | 4 个词，超过 `wordMaxWords=3` |
| 跨行断开的长单词   | `sentence` | 字符数超过 `wordMaxChars=40`  |

处理方式（从轻到重）：

1. 结果面板上一键「按词重译 / 按句重译」，只影响本次；
2. 调 `wordMaxWords` / `wordMaxChars`；
3. 用 `selectionKindMode` 固定成 `alwaysWord` / `alwaysSentence`。

### 重复词定位到别的句子

同一个词在全文出现多次时，插件靠**选区指纹**（划词瞬间抓取的左右各 40 字符）挑最像的那一处。
指纹只有在阅读器里划词时才拿得到；从主窗口用快捷键触发时没有指纹，只能退化为
「第一个词边界命中的位置」。

### 弹窗关掉后译文没了

划词译文是内联在弹窗里的：请求返回前弹窗被关闭，结果就没有地方显示。
需要保留结果时用快捷键打开结果面板，面板不会随弹窗消失。

### 音标为什么可能不准

音标由大模型生成，不是查词典：常见词基本可靠，罕见词、专有名词、屈折形式可能出错。
划词模板固定输出三行，短语 / 缩写 / 专有名词也会给出音标，但这类内容更容易硬编，关键发音请以词典为准。

### 请求超时或很慢

- 调大设置里的「请求超时」（默认 30 秒）；
- 换更快的模型（`gpt-4o-mini` / `deepseek-chat` 都属于低价快速档）；
- 检查网络与代理。翻译请求不经过任何中转服务器，直连 `baseURL`；
- 中国大陆访问 OpenAI 通常需要代理；也可以把 `baseURL` 换成自建网关或 DeepSeek。

### 认证失败（401 / 403）

- Key 是否复制完整、是否有多余空格；
- 该 Key 是否有目标模型的权限（有些账号只能访问部分模型）；
- `baseURL` 是否正确：`https://api.openai.com/v1` 与 `https://api.deepseek.com/v1`；
  只填主机名时插件会自动补 `/v1`。

### Token 成本大概是多少

- 划词：选中文本 + 所在句 + 模板，通常几十到几百 token，远低于整段翻译；
- 划句：选中文本 + 模板；开启 `sentenceContextNeighbors` 后会多带前后两句，上限约为三倍；
- `maxSentenceChars`（默认 400）限制单句上下文长度，避免把整页当上下文。

## 完整已知限制

1. **扫描版 / 图片型 PDF 没有上下文**。没有文本层时取不到所在句，面板会提示「未取到上下文」
   并降级为纯词义翻译；先做 OCR 即可恢复。
2. **句子定位依赖文本层质量**。双栏排版、页眉页脚、脚注混排可能导致句子边界偏移，
   此时会退化为字符窗口或纯词义翻译。
3. **公式与表格**：PDF 文本层里的公式往往乱序，译文可能失真；建议只选普通正文。
4. **Token 成本**：划词每次带一句上下文，比纯词翻译贵但远低于整段翻译；
   划句开启 `sentenceContextNeighbors` 后上下文最多翻三倍。
5. **选区类型可能误判**。典型误判见上文；面板可一键切换重译，也可调阈值或强制模式。
6. **不支持 Zotero 6**。插件基于 Zotero 7 的 bootstrap 与阅读器 API。
7. **划词弹窗按钮的位置 / 样式**受阅读器版本影响，Zotero 升级后可能需要适配。
8. **快捷键首次需先划一次词**。`keydown` 监听在阅读器首次渲染划词弹窗时才绑定到该文档。
9. **暂不支持把译文写回注释 / 笔记**（计划 v0.2），面板目前只提供复制。
10. **EPUB 的上下文来源分三层**：附件全文缓存（EPUB 跳过）→ 阅读器文档（锚点块优先，含嵌套
    iframe）→ Zotero 的 EPUB 解析器。最后一级要读整本书，**首次触发会慢 1～3 秒**
    （之后按附件缓存）；单本上限 200 万字符。
11. **没有选区指纹时可能取到重复词的错误位置**。主窗口用快捷键触发时拿不到指纹；
    在阅读器内划词触发则没问题。
12. **划词译文是内联的**：请求返回前弹窗被关闭，译文不会再出现在别处；
    需要完整信息请用快捷键打开结果面板。
13. **音标由大模型生成**：常见词基本可靠，罕见词、专有名词、屈折形式或短语可能不准；
    关键发音请以词典为准。
14. **暂无流式输出、术语表、全文 / 段落翻译**，这些都在路线图里（见 README）。
15. **不支持 Zotero 的非阅读器划词场景**（如元数据面板、笔记编辑器）的上下文定位；
    这些位置通过快捷键只能做纯词义翻译。

## 反馈问题

开 Issue 时请附上：

- Zotero 版本、Sense Lingo 版本（设置页底部会显示构建时间）；
- 服务商与模型名（**不要贴 API Key**）；
- `帮助 → 调试输出` 里相关的 `Sense Lingo` 日志（开启 debug 时注意日志可能包含原文）；
- 能复现问题的最小 PDF / EPUB 片段类型（扫描版？双栏？EPUB？）。
