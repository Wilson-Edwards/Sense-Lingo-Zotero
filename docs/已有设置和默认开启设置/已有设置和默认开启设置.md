# 已有设置与默认开启项

本文记录 Sense Lingo 当前已有的插件设置，以及新安装时的默认值。默认值以
[`addon/prefs.js`](../../addon/prefs.js) 为准；所有插件偏好均使用
`extensions.zotero.sense-lingo.` 前缀保存。

常规设置在 Zotero 的 `编辑 / Edit → 设置 / Settings → Sense Lingo` 中修改。标为“配置编辑器”的项未在设置页提供输入框，可在 `高级 → 配置编辑器（about:config）` 中搜索此前缀后修改。

## 默认开启与关闭

### 默认开启

下列布尔设置默认值为 `true`：

| 设置                               | 默认行为                                                                                       |
| ---------------------------------- | ---------------------------------------------------------------------------------------------- |
| 划词上下文 `useContext`            | 划词翻译会携带该词所在句，用于词义、词性和搭配辨析。                                           |
| 弹窗翻译按钮 `showInPopup`         | 在阅读器的划词弹窗中显示“翻译”按钮。                                                           |
| 快捷键 `shortcutEnabled`           | 启用 `Ctrl/⌘ + Shift + T` 触发翻译。                                                           |
| 流式输出 `stream`                  | 译文生成时逐步显示。                                                                           |
| 禁止思考 `disableThinking`         | 默认勾选；仅 ClinePass 会实际发送关闭 reasoning 的请求参数，其他服务商不会因此收到不兼容字段。 |
| 本地翻译缓存 `cacheEnabled`        | 优先查找当前 EPUB 的本地翻译缓存。                                                             |
| 严格句子匹配 `cacheStrictSentence` | 同一个词只有在相同句子中才命中缓存，优先保证义项准确。                                         |
| 翻译后写入缓存 `autoCacheOnMiss`   | AI 翻译成功后，将结果写入本地缓存。                                                            |

### 默认关闭

下列布尔设置默认值为 `false`：

| 设置                                        | 默认行为                                                         |
| ------------------------------------------- | ---------------------------------------------------------------- |
| 划句邻句上下文 `sentenceContextNeighbors`   | 划句翻译不额外传入前后各一句。                                   |
| 自动翻译 `autoTranslate`                    | 选中文本后不自动发起请求，需点按钮或使用快捷键。                 |
| 调试日志 `debug`                            | 不输出详细调试日志。                                             |
| 单条缓存回退 `cacheSingleCandidateFallback` | 只有一条候选缓存、但句子不匹配时，仍不使用该缓存，避免错误义项。 |
| 打开 EPUB 自动预翻译 `prefetchOnOpen`       | 打开 EPUB 不会自动调用模型，避免意外产生 API 费用。              |

## 设置清单

### 服务商与请求参数

| 设置页名称     | 偏好键             | 默认值         | 说明                                                                     |
| -------------- | ------------------ | -------------- | ------------------------------------------------------------------------ |
| 服务商预设     | `provider`         | `openai`       | 可选 OpenAI、DeepSeek、ClinePass、Command Code 或 OpenAI 兼容的 Custom。 |
| API Key        | `apiKey`           | 空             | 点击翻译使用的密钥；必须自行填写。                                       |
| 接口地址       | `baseURL`          | 空             | 空值时使用所选服务商预设地址。                                           |
| 模型           | `model`            | 空             | 空值时使用服务商预设模型。OpenAI 的预设模型为 `gpt-4o-mini`。            |
| 服务商配置存档 | `providerConfigs`  | 空 JSON 字符串 | 为每个服务商分别保存 API Key、接口地址和模型；切换服务商不会覆盖彼此。   |
| 温度           | `temperature`      | `"0.3"`        | 字符串存储，实际使用时限制在 0–2；值越低，结果通常越稳定。               |
| 最大 tokens    | `maxTokens`        | `1024`         | 单次模型回复的 token 上限。                                              |
| 请求超时       | `requestTimeoutMs` | `30000`        | 单位为毫秒。流式输出时按“无数据空闲时间”计时。                           |
| 流式输出       | `stream`           | `true`         | 开启时边接收边展示译文。                                                 |
| 禁止思考       | `disableThinking`  | `true`         | 仅 ClinePass 支持；其他服务商的设置页开关会置灰，不发送该参数。          |

### 预处理服务商

整本 EPUB 的预翻译可与点击翻译使用不同服务商；留空时完全跟随上方的点击翻译服务商。

| 设置页名称           | 偏好键                    | 默认值         | 说明                                      |
| -------------------- | ------------------------- | -------------- | ----------------------------------------- |
| 预处理服务商         | `prefetchProvider`        | 空             | 空值表示“跟随翻译服务商”。                |
| 预处理 API Key       | `prefetchApiKey`          | 空             | 仅在单独选择预处理服务商后生效。          |
| 预处理接口地址       | `prefetchBaseURL`         | 空             | 空值时使用该预设服务商的地址。            |
| 预处理模型           | `prefetchModel`           | 空             | 空值时使用该预设服务商的模型。            |
| 预处理服务商配置存档 | `prefetchProviderConfigs` | 空 JSON 字符串 | 与点击翻译的 `providerConfigs` 独立保存。 |

温度、最大 tokens、请求超时、流式输出和禁止思考由两个服务商作用域共享；预翻译请求本身固定使用非流式方式。

### 选区与上下文

| 设置页名称           | 偏好键                     | 默认值  | 说明                                       |
| -------------------- | -------------------------- | ------- | ------------------------------------------ |
| 选区类型判定         | `selectionKindMode`        | `auto`  | 自动判定；也可强制一律按词或一律按句处理。 |
| 判为词的最大词数     | `wordMaxWords`             | `3`     | 自动判定时，超过此词数的选区按句处理。     |
| 判为词的最大字符数   | `wordMaxChars`             | `40`    | 自动判定时，超过此字符数的选区按句处理。   |
| 划词时带出所在句     | `useContext`               | `true`  | 为词义消歧提供句子上下文。                 |
| 划句时带出前后各一句 | `sentenceContextNeighbors` | `false` | 开启后可将邻句填入提示词变量。             |
| 单句上下文长度上限   | `maxSentenceChars`         | `400`   | 超出时会截断上下文。                       |

### 提示词与语言

| 设置页名称             | 偏好键                  | 默认值         | 说明                                                                 |
| ---------------------- | ----------------------- | -------------- | -------------------------------------------------------------------- |
| 划词当前模板           | `promptProfileWord`     | `word`         | 默认使用内置“划词 · 语境辨析”模板。                                  |
| 划句当前模板           | `promptProfileSentence` | `sentence`     | 默认使用内置“划句 · 通顺翻译”模板。                                  |
| 提示词模板库           | `promptProfiles`        | 空 JSON 字符串 | 保存自定义模板；空值时使用内置划词、划句模板。                       |
| 目标语言（配置编辑器） | `targetLang`            | `zh-CN`        | 替换提示词中的 `{targetLang}`，可改为 `English`、`ja-JP` 等。        |
| 源语言（配置编辑器）   | `sourceLang`            | `auto`         | 可供自定义提示词中的 `{sourceLang}` 使用；内置模板默认不使用该变量。 |

内置划词模板要求输出“释义（词性）+ 美式音标 + 英式音标”三行；内置划句模板输出忠实、通顺的目标语言译文。

### 界面与高级

| 设置页名称             | 偏好键            | 默认值  | 说明                                              |
| ---------------------- | ----------------- | ------- | ------------------------------------------------- |
| 划词弹窗中显示翻译按钮 | `showInPopup`     | `true`  | 关闭后不在划词弹窗注入翻译按钮。                  |
| 选中后自动翻译         | `autoTranslate`   | `false` | 开启后无需点按钮；没有可用 API Key 时会静默跳过。 |
| 启用快捷键             | `shortcutEnabled` | `true`  | 快捷键为 `Ctrl/⌘ + Shift + T`。                   |
| 译文字号               | `popupFontSize`   | `12`    | 单位为 px，保存时限制为 8–32。                    |
| 输出调试日志           | `debug`           | `false` | 日志可在 Zotero 的“帮助 → 调试输出”中查看。       |

### 本地缓存与 EPUB 预翻译

| 设置页名称             | 偏好键                         | 默认值   | 说明                                                      |
| ---------------------- | ------------------------------ | -------- | --------------------------------------------------------- |
| 启用本地翻译缓存       | `cacheEnabled`                 | `true`   | 查询命中后直接显示缓存译文，不再请求模型。                |
| 严格句子匹配           | `cacheStrictSentence`          | `true`   | 词和所在句均匹配才命中，降低一词多义误命中的风险。        |
| 只有一条记录时仍然使用 | `cacheSingleCandidateFallback` | `false`  | 允许句子不同时复用唯一候选缓存；可能出现错误义项。        |
| 翻译成功后写入缓存     | `autoCacheOnMiss`              | `true`   | 未命中时的成功点击翻译会逐步积累到缓存。                  |
| 打开 EPUB 自动预翻译   | `prefetchOnOpen`               | `false`  | 开启后打开 EPUB 即启动预翻译，不经确认且会消耗额度。      |
| 每批条数               | `prefetchBatchSize`            | `12`     | 预翻译时合并到同一请求中的条目数。                        |
| 并发请求数             | `prefetchConcurrency`          | `2`      | 运行时最低为 1、最高为 8。                                |
| 请求间隔               | `prefetchDelayMs`              | `200`    | 单位为毫秒；也作为重试退避的基础时间。                    |
| 每词最多句数           | `prefetchMaxSentencesPerWord`  | `3`      | 同一词最多保留多少个句子实例进行预翻译。                  |
| 预处理语言过滤         | `prefetchLanguageFilter`       | `system` | 默认按 Zotero 界面语言；也可选 `none` / `han` / `latin`。 |

## 补充说明

- 所有设置修改后无需重启；下一次翻译或预翻译任务会读取新值。
- `temperature`、`providerConfigs`、`prefetchProviderConfigs` 与 `promptProfiles` 都以字符串保存：前者是因为 Firefox 偏好不支持浮点数，后三者是 JSON 字符串。
- API Key 明文保存在 Zotero 偏好中。导出或共享个人配置前，应先检查并清除密钥。
- 缓存位于插件私有 SQLite 数据库。设置页可查看统计、手动预翻译选中的 EPUB、停止任务和清空缓存。

更完整的配置和服务商说明见 [配置项参考](../configuration.md)。
